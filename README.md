# Банда

Один сайт для Лизардины, Вики и Насти. Главная — `index.html`.

## Где что лежит

* `main/` — главная: `content.js` (текст и подписи), `app.js` (поведение), `styles.css` (оформление), `photos/` (фотографии поздравлений).
* `friends/liza/` — Лизардина: своя страница, тексты, оформление, фотографии, рисунки, рукописные элементы, обложки видео.
* `friends/vika/` и `friends/nastya/` — отдельные страницы и папки для будущих материалов.
* `shared/fonts/` — общий рукописный шрифт Caveat.
* `shared/placeholders/` — общие заглушки.
* `shared/audio/` — звуковое сопровождение всего сайта.
* `main/audio/` и `friends/*/audio/` — звук для конкретной страницы.
* `shared/audio-config.js` — места для будущих ссылок на звук. Сейчас все значения пустые; музыка не играет. Когда будут записи, добавим кнопку воспроизведения по нажатию.
* `docs/` — сведения об обработке фотографий и публикации (в рабочем проекте).

Все пути к материалам в `content.js` считаются от HTML своей страницы. Например, Лиза: `photos/hero/wonderful.webp`; главная: `photos/from-me-01.jpg` в данных задаётся как `main/photos/from-me-01.jpg`, поскольку её HTML находится в корне.

Для Вики и Насти папки уже созданы: `photos/originals`, `photos/hero`, `photos/school`, `photos/gallery`, `drawings`, `handwriting`, `video-covers`, `audio`. `content.js` хранит имя и будущее содержимое страницы.

В рабочей версии исходные JPG и полные PNG Лизы хранятся в её `photos/originals` и `photos/cutouts`. Публичная версия содержит только используемые фото. Старые адреса `lizardina.html`, `vika.html`, `nastya.html` переводят на новые страницы.

## Открыть и изменить

Дважды нажми `ОТКРЫТЬ-САЙТ.cmd` (нужен Node.js) или выполни `npm start`. Адрес — http://127.0.0.1:4173. Можно открыть `index.html` без сервера.
