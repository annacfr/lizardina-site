# Лизардина

Публичная версия личного мобильного сайта-подарка.

В этом репозитории только файлы сайта и фотографии, которые он показывает. Исходные JPG, история разработки и рабочие материалы хранятся отдельно в закрытом проекте.

GitHub Pages публикует ветку `main`, папку `/`. Тексты и подписи находятся в `content.js`.
