# Музыка «Банды»

Главная: main/audio/hymn.mp3. Лиза, Вика, Настя: friends/имя/audio/.
Обложки добавляйте в audio/covers нужной страницы, затем укажите cover в shared/audio-config.js (путь от корня сайта).
Там же можно заменить title и src или заменить второй null на объект { title, src, cover } для второй песни.
Звук запускается только по нажатию и не прерывается при прокрутке. При переходе на другую страницу проигрыватель сменяется. Предварительной загрузки MP3 нет. Нажатие на видео Лизы ставит песню на паузу.
